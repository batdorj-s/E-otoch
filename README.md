# Eotoch - Монголын Эрүүл Мэндийн AI Туслах

Eotoch бол Монгол хүмүүсийн эрүүл мэндийн онцлогт тохирсон (STEPS судалгаа болон Kaggle өгөгдөл дээр суурилсан), хиймэл оюун ухаанаар дамжуулан өвчлөлийн эрсдэлийг үнэлж, персонал зөвлөгөө өгөх систем юм.

### Үндсэн боломжууд
- AI Эрсдэлийн Үнэлгээ: Чихрийн шижин, зүрх судас, хавдрын эрсдэлийг 12 асуултаар тодорхойлно.
- **Офлайн RAG Мэдлэгийн Сан (New)**: Монгол улсын STEPS 2005, 2013 болон БХӨ бодлогын судалгааны тайлангаас бэлтгэсэн мэдлэгийн бааз дээр суурилан хэрэглэгчийн өгөгдлийг улсын дундажтай харьцуулна.
- **Ollama AI Офлайн Зөвлөгөө (New)**: Үүлэн технологиос хамааралгүйгээр локал Llama 3 (эсвэл бусад нээлттэй LLM) ашиглан 100% офлайн зөвлөмж өгөх боломжтой.
- **Дуут Туслах (Speech-to-Text & Text-to-Speech) (New)**:
  - **Ярианаас Текст хөрвүүлэгч (STT):** Бусад зовиуруудаа гараас бичихгүйгээр яриагаар (Монгол хэлээр) хэлж оруулах боломжтой (webkitSpeechRecognition технологиор 100% локал ажиллана).
  - **Текстээс Яриа үүсгэгч (TTS):** Хиймэл оюуны бичсэн зөвлөгөөг Монгол хэлээр дуугаар сонсох боломжтой. **Chimege API** (Token ашиглан байгалийн мэт дуугаралт) болон хөтчийн үндсэн **SpeechSynthesis** хосолсон систем.
- Machine Learning Engine: Kaggle-ийн олон улсын өвчлөлийн логигийг STEPS статистиктай нэгтгэсэн Random Forest модел (ONNX Runtime Web ашиглан хөтөч дээр шууд ажиллана).
- Эмнэлэг Хайгч: Хэрэглэгчийн байршилд ойрхон улсын болон хувийн эмнэлгүүдийг харуулна.
- Дижитал Тайлан: Өөрийн эрүүл мэндийн эрсдэлийг PDF хэлбэрээр татаж авах боломжтой.

### Технологийн стек
- Frontend: React 18, TypeScript, Vite
- Styling: Tailwind CSS, Radix UI, Lucide Icons
- AI/ML: Python (Scikit-learn), ONNX Runtime (WebAssembly), Ollama (Local Llama 3) / Google Gemini AI (Backup)
- Deployment: Vercel

---

### Эхлүүлэх заавар

1. Сангуудыг суулгах:
   ```bash
   npm install
   ```

2. Офлайн AI (Ollama) тохируулах (Санал болгож буй):
   - [Ollama](https://ollama.com/) татаж суулгана.
   - Терминал дээр Llama 3 моделыг татна:
     ```bash
     ollama run llama3
     ```
   - Ollama суулгаагүй эсвэл ажиллахгүй байгаа үед систем автоматаар **Google Gemini AI API** руу шилжинэ (Fallback).

3. Google Gemini (Backup) тохируулах (Сонголтоор):
   - `.env` файл үүсгэж, Gemini API түлхүүрээ оруулна:
     ```env
     VITE_GEMINI_API_KEY=таны_түлхүүр_энд
     ```

4. Хөгжүүлэлтийн сервер асаах:
   ```bash
   npm run dev
   ```

### Модел хөгжүүлэлт (ML Approach)
Төслийн эрсдэл тооцох алгоритмыг боловсруулахдаа Kaggle-ийн олон улсын өвчлөлийн логикийг Монгол улсын STEPS 2019 судалгааны статистик тархалттай нэгтгэн 10,000 хүний синтетик өгөгдөл үүсгэж Random Forest Classifier модел сургасан. Энэ нь Монгол хүний амьдралын хэв маягийн онцлог (давсны хэрэглээ, тамхидалт, агаарын бохирдол) -ыг жинлүүр болгон авснаараа бодит үр дүнг харуулдаг.

### Дата Шинжилгээ (Data Insights)
Kaggle-ийн Heart Disease UCI өгөгдөл дээр хийсэн статистик шинжилгээний үр дүн:
- Насны хамаарал: Нас нэмэгдэх тусам зүрх судас өвчлөлийн эрсдэл нэмэгдэх хамаарал 0.34 (Positive correlation) байна.
- Зүрхний цохилт: Хамгийн өндөр зүрхний цохилт (thalch) болон эрсдэлийн хамаарал -0.37 (Negative correlation) буюу зүрхний ачаалал даах чадвар буурах нь эрсдэлийг нэмэгдүүлдэг.
- Дундаж үзүүлэлт: Өвчлөлийн датасет дэх хүмүүсийн дундаж нас 53.5, дундаж систолын даралт 132 mmHg байна.

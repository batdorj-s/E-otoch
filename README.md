Eotoch - Монголын Эрүүл Мэндийн AI Туслах

  Eotoch бол Монгол хүмүүсийн эрүүл мэндийн онцлогт тохирсон (STEPS судалгаа болон Kaggle өгөгдөл дээр суурилсан), хиймэл оюун ухаанаар дамжуулан өвчлөлийн эрсдэлийг
  үнэлж, персонал зөвлөгөө өгөх систем юм.

  ✨ Үндсэн боломжууд
   - AI Эрсдэлийн Үнэлгээ: Чихрийн шижин, зүрх судас, хавдрын эрсдэлийг 12 асуултаар тодорхойлно.
   - Gemini AI Зөвлөгөө: Хэрэглэгчийн өгөгдөлд дүн шинжилгээ хийж, Монгол хэлээр маш тодорхой эрүүл мэндийн зөвлөмж өгнө.
   - Эмнэлэг Хайгч: Хэрэглэгчийн байршилд ойрхон улсын болон хувийн эмнэлгүүдийг харуулна.
   - Дижитал Тайлан: Өөрийн эрүүл мэндийн эрсдэлийг PDF хэлбэрээр татаж авах боломжтой.

  ---

  🛠 Технологийн стек
   - Frontend: React 18, TypeScript, Vite
   - Styling: Tailwind CSS, Radix UI, Lucide Icons
   - AI Engine: Google Gemini AI (Generative Language API)
   - Deployment: Vercel

  ---

  🚀 Эхлүүлэх заавар

   1. Сангуудыг суулгах:

   1    npm install

   2. Environment Variables тохируулах:
     .env файл үүсгэж, Gemini API түлхүүрээ оруулна:

   1    VITE_GEMINI_API_KEY=таны_түлхүүр_энд

   3. Хөгжүүлэлтийн сервер асаах:
   1    npm run dev

  ---

  🏗 Архитектур

   1 src/
   2 ├── app/
   3 │   ├── components/    # Хэрэглэгчийн дэлгэцүүд (Onboarding, Result, гэх мэт)
   4 │   ├── utils/         # AI интеграц, эрсдэл тооцоолох алгоритм, storage
   5 │   └── data/          # Эмнэлгийн мэдээлэл болон тогтмол өгөгдлүүд
   6 └── styles/           # Tailwind CSS тохиргоо

  🛡 Аюулгүй байдал
  Энэхүү төсөл нь хэрэглэгчийн мэдээллийг нууцлах зорилгоор AES-256 шифрлэлт ашиглан локал санд (LocalStorage) хадгалдаг. API түлхүүрийг хэзээ ч GitHub руу ил

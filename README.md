# 🩺 Eotoch - Монголын Эрүүл Мэндийн AI Туслах

**Eotoch** бол Монгол хүмүүсийн эрүүл мэндийн онцлогт тохирсон (STEPS судалгаа болон Kaggle өгөгдөл дээр суурилсан), хиймэл оюун ухаанаар дамжуулан өвчлөлийн эрсдэлийг үнэлж, персонал зөвлөгөө өгөх систем юм.

### ✨ Үндсэн боломжууд
- **AI Эрсдэлийн Үнэлгээ:** Чихрийн шижин, зүрх судас, хавдрын эрсдэлийг 12 асуултаар тодорхойлно.
- **Gemini AI Зөвлөгөө:** Хэрэглэгчийн өгөгдөлд дүн шинжилгээ хийж, Монгол хэлээр маш тодорхой эрүүл мэндийн зөвлөмж өгнө.
- **Machine Learning Engine:** Kaggle-ийн олон улсын өвчлөлийн логикийг STEPS статистиктай нэгтгэсэн Random Forest модел.
- **Эмнэлэг Хайгч:** Хэрэглэгчийн байршилд ойрхон улсын болон хувийн эмнэлгүүдийг харуулна.
- **Дижитал Тайлан:** Өөрийн эрүүл мэндийн эрсдэлийг PDF хэлбэрээр татаж авах боломжтой.

---

### 🛠 Технологийн стек
- **Frontend:** React 18, TypeScript, Vite
- **Styling:** Tailwind CSS, Radix UI, Lucide Icons
- **AI/ML:** Python (Scikit-learn), ONNX Runtime, Google Gemini AI
- **Deployment:** Vercel

---

### 🚀 Эхлүүлэх заавар

1. **Сангуудыг суулгах:**
   ```bash
   npm install
   ```

2. **Environment Variables тохируулах:**
   `.env` файл үүсгэж, Gemini API түлхүүрээ оруулна:
   ```env
   VITE_GEMINI_API_KEY=таны_түлхүүр_энд
   ```

3. **Хөгжүүлэлтийн сервер асаах:**
   ```bash
   npm run dev
   ```

### 🧠 Модел хөгжүүлэлт (ML Approach)
Төслийн эрсдэл тооцох алгоритмыг боловсруулахдаа **Kaggle**-ийн олон улсын өвчлөлийн логикийг Монгол улсын **STEPS 2019** судалгааны статистик тархалттай нэгтгэн 10,000 хүний синтетик өгөгдөл үүсгэж **Random Forest Classifier** модел сургасан. Энэ нь Монгол хүний амьдралын хэв маягийн онцлог (давсны хэрэглээ, тамхидалт, агаарын бохирдол) -ыг жинлүүр болгон авснаараа бодит үр дүнг харуулдаг.
